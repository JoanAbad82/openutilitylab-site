      How to use this free local mode

      Use this when you have an affiliate article, review or comparison page and want a quick local friction check.

      Your HTML is processed locally in your browser. It is not uploaded, stored or sent to Open Utility Lab.

      Steps

      1. Open the affiliate article or page you want to audit.
      2. Copy the page HTML or save it as an .html file.
      3. Paste the HTML here or upload the file.
      4. Run the local analysis and review the friction report.

      Getting the HTML

      Chrome / Edge / Firefox: Right click on the page, choose View Page Source, copy all, then paste here.

      Alternative: Save Page As, choose Web Page, HTML only, then upload the .html file.

      What the score means

      The score is not a revenue prediction. It is an indicative friction score based only on observable HTML signals.

      What this detects

      • Affiliate-looking links
      • CTA signals
      • Weak tracking links
      • Commercial intent signals
      • Basic metadata and heading structure
      • Possible friction points

      What this does not detect yet

      • Live URL fetching
      • JavaScript-rendered content unless included in the provided HTML
      • Full destination-page validation
      • Revenue estimates
      • Legal or compliance guarantees
