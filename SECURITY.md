# Security Policy

## Scope

Open Utility Lab is a static public website containing browser-side utilities and project documentation.

## Reporting

Do not open public issues containing credentials, private client data, tokens, raw sensitive audit inputs, or security-sensitive personal information. Report sensitive issues privately to the repository owner.

## Data handling

Client-side tools should minimize data transfer. For Affiliate Friction Auditor, supplied HTML is processed in the browser and is not sent to an application backend for analysis. Site-level aggregate analytics, when enabled, are separate from the analyzed HTML input.

## Limitations

Public tools and reports are aids, not guarantees of security, legal compliance, revenue, SEO performance, or correctness. Review outputs before acting on them.
