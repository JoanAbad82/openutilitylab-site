Master Security Review

Available now

A Windows audit utility designed to help with a fast first-pass security review and generate a report that is easier to review and safer to share.

Version 1.0.0 is publicly available on GitHub Releases. The current Windows build is unsigned while code signing is pending, so verify the published SHA256 before running it. Source code is available on GitHub.

Affiliate Friction Auditor

Available now · Free local MVP · Private audits available

A free local audit tool for affiliate review, comparison, and commercial pages. Paste or upload HTML to detect CTA friction, affiliate signals, weak tracking patterns, commercial intent, and structural issues before deeper manual review.

  • Detects affiliate, CTA, tracking, and commercial intent signals.
  • Generates a local friction report with prioritized findings.
  • Exports summaries and audit evidence for manual review.

RealityGap

Polymarket execution-quality radar.

RealityGap scans live Polymarket markets and checks whether the visible price is close to the price you can actually execute for a selected size.

No wallet. No trading. No predictions. Execution quality only.
